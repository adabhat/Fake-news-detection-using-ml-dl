# Fake-news-detection-using-ml-dl

### This project addresses the growing threat of fake news amplified by digital platforms and social media. It highlights the limitations of manual fact-checking and proposes machine learning as a scalable solution. By leveraging NLP and ML techniques, the system aims to accurately classify news as real or fake, contributing to the fight against misinformation online.

### This fake news detection project uses a Bidirectional LSTM model built with TensorFlow/Keras, trained on preprocessed news titles. It applies NLP techniques such as tokenization, stemming, stopword removal, one-hot encoding, and padding. The model is evaluated using accuracy, confusion matrix, and classification report. Key libraries include NumPy, Pandas, NLTK, Scikit-learn, Matplotlib, and TensorFlow. The model uses an embedding layer, LSTM layers, and a sigmoid activation function to perform binary classification of news titles. 

### To run this fake news detection project, ensure Python 3.7 or above is installed, then install the necessary libraries using pip, including NumPy, Pandas, TensorFlow, NLTK, Scikit-learn, and Matplotlib. Download the required NLTK resources (punkt and stopwords) within your script. Place the Jupyter Notebook (fake news detection.ipynb) and the dataset file (train.csv) in the same directory.
